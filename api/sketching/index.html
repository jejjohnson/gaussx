    Sketching¶

    Random sketching operators \(\mathbf{S} \in \mathbb{R}^{d \times M}\) that compress a tall matrix \(\mathbf{A} \in \mathbb{R}^{M \times N}\) to \(\mathbf{S}\mathbf{A} \in \mathbb{R}^{d \times N}\) while approximately preserving the geometry of its range. \(\mathbf{S}\) is an \(\varepsilon\)-subspace embedding for \(\mathrm{range}(\mathbf{A})\) if

    \[ (1 - \varepsilon) \Vert \mathbf{A}\mathbf{x} \Vert_2 \le \Vert \mathbf{S}\mathbf{A}\mathbf{x} \Vert_2 \le (1 + \varepsilon) \Vert \mathbf{A}\mathbf{x} \Vert_2 \]

    for every \(\mathbf{x} \in \mathbb{R}^N\).

    Sketches are the foundation of the randomized linear-algebra stack (range finders, randomized SVD, sketch-and-precondition least squares).

    Sketch Size d for an \(\varepsilon\)-embedding Cost to apply
    GaussianSketch \(O(N/\varepsilon^2)\) \(O(dMN)\)
    SparseSignSketch (default for tall problems) \(O(N\log N/\varepsilon^2)\) \(O(\mathrm{nnz}\cdot MN)\)
    SRHTSketch \(O((N+\log M)\log N/\varepsilon^2)\) \(O(MN\log M)\)

    A sketch is sampled once, with an explicit PRNG key (key=None means jax.random.PRNGKey(0)), and its random draws live in the module: apply (\(\mathbf{S}\mathbf{A}\)) and apply_transpose (\(\mathbf{S}^\top \mathbf{Y}\)) always refer to the same \(\mathbf{S}\). sketch_operator sketches a matrix-free lineax operator with \(d\) transpose-matvecs, and as_operator returns \(\mathbf{S}\) itself as a lineax operator.

    # Sketch a tall Jacobian (10⁶ residuals × 200 parameters) down to 800 rows
S = gx.SparseSignSketch.sample(key, d=800, m=1_000_000, nnz=8)
SJ = S.sketch_operator(J_op)  # (800, 200), matrix-free
sv = jnp.linalg.svd(SJ, compute_uv=False)  # J's singular values, within (1 ± ε)

    class AbstractSketch(eqx.Module):
    """A random sketching matrix S ∈ ℝ^(d × M), sampled once.

        (1 − ε) ‖A x‖₂ ≤ ‖S A x‖₂ ≤ (1 + ε) ‖A x‖₂   for every x

    A sketch compresses a tall matrix A ∈ ℝ^(M × N) to S A ∈ ℝ^(d × N) with d ≪ M while
    approximately preserving the geometry of range(A). S is an ε-subspace embedding for
    range(A) when the bound above holds.

    The random draws live in the module, so `apply` and `apply_transpose` always refer
    to the same S. Concrete sketches are built with their `sample` classmethod, which
    takes a PRNG key (``key=None`` means ``jax.random.PRNGKey(0)``).

    Sketches cast their stored values to the dtype of the array they are applied to, so
    a float32 input never meets a float64 sketch.

    Attributes:
        in_size: Number of columns M of S (rows of the sketched input).
        out_size: Number of rows d of S (the sketch size).

    Examples:
        Every concrete sketch has the same interface:

        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import gaussx
        >>> sketch = gaussx.GaussianSketch.sample(jr.key(0), d=4, m=8)
        >>> isinstance(sketch, gaussx.AbstractSketch)
        True
        >>> sketch.out_size, sketch.in_size
        (4, 8)

        `apply_transpose` is the adjoint of `apply`, ⟨S x, y⟩ = ⟨x, Sᵀ y⟩:

        >>> x, y = jnp.arange(8.0), jnp.arange(4.0)
        >>> left = jnp.dot(sketch.apply(x), y)
        >>> right = jnp.dot(x, sketch.apply_transpose(y))
        >>> bool(jnp.allclose(left, right, rtol=1e-4))
        True

        `sketch_operator` rejects an operator with the wrong number of rows:

        >>> import lineax as lx
        >>> wrong = lx.MatrixLinearOperator(jnp.ones((6, 3)))
        >>> sketch.sketch_operator(wrong)
        Traceback (most recent call last):
        ...
        ValueError: Cannot sketch an operator with 6 rows using a sketch with in_size=8.
    """

    in_size: eqx.AbstractVar[int]
    out_size: eqx.AbstractVar[int]

    @abc.abstractmethod
    def apply(self, A: Float[Array, "m ..."]) -> Float[Array, "d ..."]:
        """Compute S A along the leading axis of ``A``.

        Args:
            A: Array A whose leading axis has length M.

        Returns:
            The product S A, whose leading axis has length d.
        """

    @abc.abstractmethod
    def apply_transpose(self, Y: Float[Array, "d ..."]) -> Float[Array, "m ..."]:
        """Compute Sᵀ Y along the leading axis of ``Y``.

        Args:
            Y: Array Y whose leading axis has length d.

        Returns:
            The product Sᵀ Y, whose leading axis has length M.
        """

    def sketch_operator(self, op: lx.AbstractLinearOperator) -> Float[Array, "d n"]:
        """Sketch a (possibly matrix-free) operator A.

            S A = (Aᵀ Sᵀ)ᵀ

        A `lineax.MatrixLinearOperator` is sketched directly with `apply`. Any other
        operator is sketched with d transpose-matvecs, vmapped over the rows of S; this
        materialises Sᵀ as an M × d block but never forms A.

        Args:
            op: Operator A, M × N.

        Returns:
            The dense sketch S A, d × N.

        Raises:
            ValueError: If ``op.out_size()`` is not the sketch's ``in_size``.

        Examples:
            A stored operator and a matrix-free one give the same sketch:

            >>> import jax
            >>> import jax.numpy as jnp
            >>> import jax.random as jr
            >>> import lineax as lx
            >>> import gaussx
            >>> matrix = jr.normal(jr.key(1), (8, 3))
            >>> sketch = gaussx.GaussianSketch.sample(jr.key(0), d=4, m=8)
            >>> stored = lx.MatrixLinearOperator(matrix)
            >>> structure = jax.ShapeDtypeStruct((3,), matrix.dtype)
            >>> free = lx.FunctionLinearOperator(lambda x: matrix @ x, structure)
            >>> sketched = sketch.sketch_operator(stored)
            >>> sketched.shape
            (4, 3)
            >>> bool(jnp.allclose(sketched, sketch.sketch_operator(free), rtol=1e-4))
            True
        """
        if op.out_size() != self.in_size:
            raise ValueError(
                f"Cannot sketch an operator with {op.out_size()} rows using a "
                f"sketch with in_size={self.in_size}."
            )
        if isinstance(op, lx.MatrixLinearOperator):
            # S A, on the stored matrix
            return self.apply(op.matrix)
        dtype = op.out_structure().dtype
        identity = jnp.eye(self.out_size, dtype=dtype)
        # Sᵀ = Sᵀ I_d, whose columns are the rows of S
        rows_of_sketch = self.apply_transpose(identity)
        transpose = op.transpose()
        # S A = (Aᵀ Sᵀ)ᵀ, one row of S A per column of Sᵀ
        return jax.vmap(transpose.mv, in_axes=1)(rows_of_sketch)

    def as_operator(self) -> lx.AbstractLinearOperator:
        """Return S as a matrix-free d × M lineax operator.

            x ↦ S x

        The operator's dtype is that of the first inexact array stored on the sketch.

        Returns:
            The operator S, whose matvec is `apply`.

        Examples:
            >>> import jax.numpy as jnp
            >>> import jax.random as jr
            >>> import gaussx
            >>> sketch = gaussx.SRHTSketch.sample(jr.key(0), d=4, m=10)
            >>> operator = sketch.as_operator()
            >>> operator.out_size(), operator.in_size()
            (4, 10)
            >>> x = jnp.arange(10.0)
            >>> bool(jnp.allclose(operator.mv(x), sketch.apply(x)))
            True
        """
        leaves = jax.tree.leaves(eqx.filter(self, eqx.is_inexact_array))
        dtype = leaves[0].dtype
        structure = jax.ShapeDtypeStruct((self.in_size,), dtype)
        return lx.FunctionLinearOperator(self.apply, structure)

    class GaussianSketch(_DenseSketch):
    """Gaussian sketch: i.i.d. entries S_ij ~ 𝒩(0, 1/d).

    N-dimensional subspace; applying it to an M × N matrix costs O(d M N).

    Examples:

        (2, 6)

    rows: Int[Array, "nnz m"]
    signs: Float[Array, "nnz m"]
    in_size: int = eqx.field(static=True)
    out_size: int = eqx.field(static=True)

    @classmethod
    def sample(
        cls, key: jax.Array | None, d: int, m: int, *, nnz: int = 8
    ) -> SparseSignSketch:
        """Draw a d × M sparse sign sketch.

            r_k,j ∈ {0, …, d − 1} distinct in k,   s_k,j = ±1 / √nnz

        The ``nnz`` distinct rows of each column are drawn with Floyd's algorithm,
        vectorised over columns: O(nnz² M) work, never O(d M).

        Algorithm:
            1. For each l = d − nnz, …, d − 1, draw t ~ U{0, …, l} per column.
            2. Keep t unless an earlier draw in that column took it, else keep l.
            3. Draw the signs, ±1 / √nnz.

        Args:
            key: PRNG key. ``None`` means ``jax.random.PRNGKey(0)``.
            d: Sketch size d (rows of S).
            m: Input size M (columns of S).
            nnz: Non-zeros per column; clipped to d.

        Returns:
            The sampled `SparseSignSketch`.
        """
        if key is None:
            key = jax.random.PRNGKey(0)
        nnz = min(nnz, d)
        row_key, sign_key = jax.random.split(key)
        step_keys = jax.random.split(row_key, nnz)
        rows: list[Array] = []
        # Floyd: l is never taken yet when its step begins, so the rows stay distinct.
        for step, step_key in enumerate(step_keys):
            # l = d − nnz + k
            largest_row = d - nnz + step
            # t ~ U{0, …, l}, per column
            candidate = jax.random.randint(step_key, (m,), 0, largest_row + 1)
            taken = jnp.zeros((m,), dtype=bool)
            for earlier_rows in rows:
                # t = r_k′,j, for an earlier k′
                clash = earlier_rows == candidate
                taken = taken | clash
            # r_k,j = l where t is taken, else t
            row = jnp.where(taken, largest_row, candidate)
            rows.append(row)
        # ±1
        rademacher_draw = jax.random.rademacher(sign_key, (nnz, m), dtype=float)
        # √nnz
        scale = jnp.sqrt(nnz)
        # s_k,j = ±1 / √nnz
        signs = rademacher_draw / scale
        stacked_rows = jnp.stack(rows)
        return cls(rows=stacked_rows, signs=signs, in_size=m, out_size=d)

    def apply(self, A: Float[Array, "m ..."]) -> Float[Array, "d ..."]:
        """Compute S A along the leading axis of ``A``.

            [S A]_r,: = ∑_(k, j : r_k,j = r) s_k,j A_j,:

        Args:
            A: Array A whose leading axis has length M.

        Returns:
            The product S A, whose leading axis has length d.
        """
        # in the input's dtype, so a float32 input never meets a float64 sketch
        signs = self.signs.astype(A.dtype)
        # s_k,j A_j,:
        contributions = einsum(signs, A, "k m, m ... -> k m ...")
        flat_contributions = rearrange(contributions, "k m ... -> (k m) ...")
        flat_rows = rearrange(self.rows, "k m -> (k m)")
        # [S A]_r,: = ∑_(k, j : r_k,j = r) s_k,j A_j,:
        return jax.ops.segment_sum(
            flat_contributions, flat_rows, num_segments=self.out_size
        )

    def apply_transpose(self, Y: Float[Array, "d ..."]) -> Float[Array, "m ..."]:
        """Compute Sᵀ Y along the leading axis of ``Y``.

            [Sᵀ Y]_j,: = ∑_k s_k,j Y_(r_k,j),:

        Args:
            Y: Array Y whose leading axis has length d.

        Returns:
            The product Sᵀ Y, whose leading axis has length M.
        """
        # in the input's dtype, so a float32 input never meets a float64 sketch
        signs = self.signs.astype(Y.dtype)
        # Accumulate one gather per non-zero: O(M N) memory, not O(nnz M N).
        # s_0,j Y_(r_0,j),:
        first_signs = signs[0]
        first_gather = Y[self.rows[0]]
        out = einsum(first_signs, first_gather, "m, m ... -> m ...")
        for k in range(1, signs.shape[0]):
            # s_k,j
            signs_k = signs[k]
            # Y_(r_k,j),:
            gather_k = Y[self.rows[k]]
            # s_k,j Y_(r_k,j),:
            term = einsum(signs_k, gather_k, "m, m ... -> m ...")
            # ∑_k s_k,j Y_(r_k,j),:
            out = out + term
        return out

    row_key, sign_key = jax.random.split(key)
    step_keys = jax.random.split(row_key, nnz)
    rows: list[Array] = []
    # Floyd: l is never taken yet when its step begins, so the rows stay distinct.
    for step, step_key in enumerate(step_keys):
        # l = d − nnz + k
        largest_row = d - nnz + step
        # t ~ U{0, …, l}, per column
        candidate = jax.random.randint(step_key, (m,), 0, largest_row + 1)
        taken = jnp.zeros((m,), dtype=bool)
        for earlier_rows in rows:
            # t = r_k′,j, for an earlier k′
            clash = earlier_rows == candidate
            taken = taken | clash
        # r_k,j = l where t is taken, else t
        row = jnp.where(taken, largest_row, candidate)
        rows.append(row)
    # ±1
    rademacher_draw = jax.random.rademacher(sign_key, (nnz, m), dtype=float)
    # √nnz
    scale = jnp.sqrt(nnz)
    # s_k,j = ±1 / √nnz
    signs = rademacher_draw / scale
    stacked_rows = jnp.stack(rows)
    return cls(rows=stacked_rows, signs=signs, in_size=m, out_size=d)

    # Jitted: eagerly, the gather, padding, transform and row selection would
    # each dispatch (and compile) as separate programs.
    @eqx.filter_jit
    def apply(self, A: Float[Array, "m ..."]) -> Float[Array, "d ..."]:
        """Compute S A along the leading axis of ``A``.

            S A = R H [D P A; 0] / √d

        Algorithm:
            1. Permute and sign the rows, D P A.
            2. Zero-pad to M₂ rows and apply H along the padded axis.
            3. Keep the rows R and scale by 1 / √d.

        Args:
            A: Array A whose leading axis has length M.

        Returns:
            The product S A, whose leading axis has length d.
        """
        # in the input's dtype, so a float32 input never meets a float64 sketch
        signs = self.signs.astype(A.dtype)
        # P A
        permuted = A[self.permutation]
        # D P A
        signed = einsum(signs, permuted, "m, m ... -> m ...")
        padded_size = _padded_size(self.in_size)
        padding = jnp.zeros((padded_size - self.in_size, *A.shape[1:]), dtype=A.dtype)
        # [D P A; 0]
        padded = jnp.concatenate([signed, padding])
        rows_last = rearrange(padded, "m ... -> ... m")
        # H [D P A; 0]
        transformed = hadamard_transform(rows_last)
        # R H [D P A; 0]
        selected = transformed[..., self.rows]
        rows_first = rearrange(selected, "... d -> d ...")
        # √(M₂ / d) R (H / √M₂) = R H / √d with the unnormalised transform
        return rows_first / math.sqrt(self.out_size)

    @eqx.filter_jit
    def apply_transpose(self, Y: Float[Array, "d ..."]) -> Float[Array, "m ..."]:
        """Compute Sᵀ Y along the leading axis of ``Y``.

            Sᵀ Y = Pᵀ D (H Rᵀ Y)_1:M / √d

        Algorithm:
            1. Place Y on the rows R of M₂ zeros, Rᵀ Y, and apply H.
            2. Keep the first M rows, which the padding of `apply` read as zero.
            3. Sign and undo the permutation, then scale by 1 / √d.

        Args:
            Y: Array Y whose leading axis has length d.

        Returns:
            The product Sᵀ Y, whose leading axis has length M.
        """
        padded_size = _padded_size(self.in_size)
        zeros = jnp.zeros((padded_size, *Y.shape[1:]), dtype=Y.dtype)
        # Rᵀ Y
        padded = zeros.at[self.rows].set(Y)
        rows_last = rearrange(padded, "m ... -> ... m")
        # H Rᵀ Y
        transformed = hadamard_transform(rows_last)
        rows_first = rearrange(transformed, "... m -> m ...")
        # in the input's dtype, so a float32 input never meets a float64 sketch
        signs = self.signs.astype(Y.dtype)
        # (H Rᵀ Y)_1:M
        truncated = rows_first[: self.in_size]
        # D (H Rᵀ Y)_1:M
        signed = einsum(signs, truncated, "m, m ... -> m ...")
        permuted_zeros = jnp.zeros_like(signed)
        # Pᵀ D (H Rᵀ Y)_1:M
        unpermuted = permuted_zeros.at[self.permutation].set(signed)
        # Sᵀ Y = Pᵀ D (H Rᵀ Y)_1:M / √d
        return unpermuted / math.sqrt(self.out_size)

    @classmethod
    def sample(
        cls,
        key: jax.Array | None,
        d: int,
        m: int,
        *,
        probabilities: Float[ArrayLike, " m"] | None = None,
    ) -> RowSamplingSketch:
        """Draw a d × M row-sampling sketch.

            i_k ~ p,   w_k = 1 / √(d p_(i_k))

        Algorithm:
            1. Normalise the weights to the probabilities p, or take p_i = 1 / M.
            2. Draw d rows i_k ~ p with replacement.
            3. Scale each sampled row by w_k.

        Args:
            key: PRNG key. ``None`` means ``jax.random.PRNGKey(0)``.
            d: Number d of sampled rows.
            m: Input size M (columns of S).
            probabilities: Non-negative sampling weights, of length M, normalised
                internally to p. ``None`` means uniform.

        Returns:
            The sampled `RowSamplingSketch`.
        """
        if key is None:
            key = jax.random.PRNGKey(0)
        if probabilities is None:
            # p_i = 1 / M
            row_probabilities = jnp.full((m,), 1.0 / m)
        else:
            row_weights = jnp.asarray(probabilities)
            # the total, to normalise by
            total_weight = jnp.sum(row_weights)
            # p_i = weight_i / total
            row_probabilities = row_weights / total_weight
        # i_k ~ p
        rows = jax.random.choice(key, m, (d,), replace=True, p=row_probabilities)
        # p_(i_k)
        sampled_probabilities = row_probabilities[rows]
        # d p_(i_k)
        scaled_probabilities = d * sampled_probabilities
        # √(d p_(i_k))
        root_probabilities = jnp.sqrt(scaled_probabilities)
        # w_k = 1 / √(d p_(i_k))
        weights = 1.0 / root_probabilities
        return cls(rows=rows, weights=weights, in_size=m, out_size=d)

    def apply(self, A: Float[Array, "m ..."]) -> Float[Array, "d ..."]:
        """Compute S A along the leading axis of ``A``.

            [S A]_k,: = w_k A_(i_k),:

        Args:
            A: Array A whose leading axis has length M.

        Returns:
            The product S A, whose leading axis has length d.
        """
        # in the input's dtype, so a float32 input never meets a float64 sketch
        weights = self.weights.astype(A.dtype)
        # A_(i_k),:
        sampled_rows = A[self.rows]
        # [S A]_k,: = w_k A_(i_k),:
        return einsum(weights, sampled_rows, "d, d ... -> d ...")

    def apply_transpose(self, Y: Float[Array, "d ..."]) -> Float[Array, "m ..."]:
        """Compute Sᵀ Y along the leading axis of ``Y``.

            [Sᵀ Y]_i,: = ∑_(k : i_k = i) w_k Y_k,:

        Args:
            Y: Array Y whose leading axis has length d.

        Returns:
            The product Sᵀ Y, whose leading axis has length M.
        """
        # in the input's dtype, so a float32 input never meets a float64 sketch
        weights = self.weights.astype(Y.dtype)
        # w_k Y_k,:
        weighted = einsum(weights, Y, "d, d ... -> d ...")
        zeros = jnp.zeros((self.in_size, *Y.shape[1:]), dtype=Y.dtype)
        # [Sᵀ Y]_i,: = ∑_(k : i_k = i) w_k Y_k,:
        return zeros.at[self.rows].add(weighted)

    hadamard_transform(x: Float[Array, '... d']) -> Float[Array, '... d'] ¶

    Unnormalized Walsh-Hadamard transform along the last axis.

    H_d x,   H_2h = [H_h, H_h; H_h, −H_h],   H₁ = 1

    Uses log₂ d butterfly passes: O(d log d) work, no d × d matrix. Applying it twice returns d x.

    The passes use the constant-geometry (Pease) ordering: every pass reads adjacent pairs and writes their sums to the first half, their differences to the second,

    y_j = x_2j + x_2j+1,   y_j+d/2 = x_2j − x_2j+1,   j = 0, …, d/2 − 1

    that is, one pass is (H₂ ⊗ I_d/2) Π with Π the perfect unshuffle. Pass k butterflies bit k of the original index, the same bit the in-place Sylvester pass with stride 2^k uses, and log₂ d unshuffles rotate the index bits back to the identity, so the result is H_d x with the same floating-point additions in the same order. As each pass has the same shape, the loop is a jax.lax.fori_loop whose body is traced once, so tracing cost does not grow with log₂ d.

    Algorithm
    1. Return x when d = 1, since H₁ = 1.
    2. Split x into its even and odd entries (the same reshape every pass).
    3. Write the sums to the first half and the differences to the second.
    4. Repeat steps 2 and 3 for log₂ d passes in total.

    def hadamard_transform(x: Float[Array, "... d"]) -> Float[Array, "... d"]:
    """Unnormalized Walsh-Hadamard transform along the last axis.

        H_d x,   H_2h = [H_h, H_h; H_h, −H_h],   H₁ = 1

    Uses log₂ d butterfly passes: O(d log d) work, no d × d matrix. Applying it twice
    returns d x.

    The passes use the constant-geometry (Pease) ordering: every pass reads adjacent
    pairs and writes their sums to the first half, their differences to the second,

        y_j = x_2j + x_2j+1,   y_j+d/2 = x_2j − x_2j+1,   j = 0, …, d/2 − 1

    that is, one pass is (H₂ ⊗ I_d/2) Π with Π the perfect unshuffle. Pass k butterflies
    bit k of the original index, the same bit the in-place Sylvester pass with stride
    2^k uses, and log₂ d unshuffles rotate the index bits back to the identity, so the
    result is H_d x with the same floating-point additions in the same order. As each
    pass has the same shape, the loop is a `jax.lax.fori_loop` whose body is traced
    once, so tracing cost does not grow with log₂ d.

    Algorithm:
        1. Return x when d = 1, since H₁ = 1.
        2. Split x into its even and odd entries (the same reshape every pass).
        3. Write the sums to the first half and the differences to the second.
        4. Repeat steps 2 and 3 for log₂ d passes in total.

    Args:
        x: Array x whose last axis has a power-of-two length d. Leading axes are batch
            axes.

    Returns:
        The transform H_d x, the same shape as ``x``.

    Raises:
        ValueError: If the last axis is not a power of two.

    Examples:
        The first column of H₄, and the 2 × 2 butterfly:

        >>> import jax.numpy as jnp
        >>> from gaussx import hadamard_transform
        >>> hadamard_transform(jnp.array([1.0, 0.0, 0.0, 0.0])).tolist()
        [1.0, 1.0, 1.0, 1.0]
        >>> hadamard_transform(jnp.array([1.0, 2.0])).tolist()
        [3.0, -1.0]

        Leading axes are batch axes, and applying it twice returns d x:

        >>> batch = jnp.stack([jnp.arange(8.0), jnp.ones(8)])
        >>> twice = hadamard_transform(hadamard_transform(batch))
        >>> bool(jnp.allclose(twice, 8.0 * batch))
        True

        A last axis that is not a power of two is rejected:

        >>> hadamard_transform(jnp.ones(3))
        Traceback (most recent call last):
        ...
        ValueError: hadamard_transform needs a power-of-two last axis, got 3.

    References:
        Pease, M. C. (1968). An adaptation of the fast Fourier transform for
        parallel processing. *Journal of the ACM*, 15(2), 252-264.
    """
    size = x.shape[-1]
    if not _is_power_of_two(size):
        raise ValueError(
            f"hadamard_transform needs a power-of-two last axis, got {size}."
        )
    if size == 1:
        # H₁ x = x
        return x
    # (+1, −1): a + (−1) b equals a − b exactly in IEEE arithmetic.
    sign = jnp.asarray([1, -1], dtype=x.dtype)

    def butterfly(_: int, values: Array) -> Array:
        # (x_2j, x_2j+1)
        even_entries, odd_entries = rearrange(values, "... (h two) -> two ... h", two=2)
        # (x_2j+1, −x_2j+1)
        signed_odd = einx.multiply("two, ... h -> ... two h", sign, odd_entries)
        # y_j = x_2j + x_2j+1,   y_j+d/2 = x_2j − x_2j+1
        return einx.add("... h, ... two h -> ... (two h)", even_entries, signed_odd)

    # log₂ d
    num_passes = size.bit_length() - 1
    return jax.lax.fori_loop(0, num_passes, butterfly, x)

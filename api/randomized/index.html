    Randomized Linear Algebra¶

    Randomized factorisations that touch a matrix only through a few columns or matvecs. They take an explicit PRNG key; key=None means jax.random.PRNGKey(0).

    Range finder, QB, SVD and eigh¶

    Randomized subspace iteration (Halko, Martinsson & Tropp, 2011) finds an orthonormal basis \(\mathbf{Q}\) for the dominant range of a matrix-free operator \(\mathbf{A}\) from a block of \(\ell = k + p\) matvecs. For a Gaussian test matrix,

    \[ \mathbb{E} \Vert \mathbf{A} - \mathbf{Q}\mathbf{Q}^\top \mathbf{A} \Vert_2 \le \left(1 + \sqrt{\frac{k}{p-1}}\right) s_{k+1} + \frac{e\sqrt{k+p}}{p} \left(\sum_{j>k} s_j^2\right)^{1/2} \]

    with \(s_j\) the singular values of \(\mathbf{A}\).

    The tail term hurts for slowly decaying spectra (Matérn-½ Gram matrices, most geophysical fields); n_power_iter=q applies the bound to \((\mathbf{A}\mathbf{A}^\top)^q \mathbf{A}\), whose singular values are \(s_j^{2q+1}\), for \(2q\) more passes. Use n_power_iter >= 2 there. These methods target the top of the spectrum; the small end (e.g. the smallest Laplacian eigenvalues) is Lanczos / LOBPCG territory.

    qb returns \(\mathbf{Q}\) and \(\mathbf{B} = \mathbf{Q}^\top \mathbf{A}\), randomized_svd lifts the SVD of \(\mathbf{B}\), and randomized_eigh is the Rayleigh–Ritz projection \(\mathbf{Q}^\top \mathbf{A} \mathbf{Q}\) for symmetric, possibly indefinite, operators. svd(op, rank=k, method="randomized") and eig(op, rank=k, method="randomized") route here; Lanczos stays the default.

    # 50 EOFs of a (100k pixels × 3650 days) anomaly matrix, available only as a matvec
U, s, Vt = gx.randomized_svd(anomalies_op, 50, oversample=10, n_power_iter=2, key=key)
eofs, pcs = U, einx.multiply("k, k t -> k t", s, Vt)

    Orthonormal basis Q for the dominant range of A.

    Q = orth((A Aᵀ)^q A Ω),   Ω ∈ ℝ^(N × ℓ),   ℓ = k + p

    For a Gaussian Ω and q = 0 (Halko, Martinsson & Tropp, 2011, Thm 10.6), with singular values s_j of A,

    𝔼 ‖A − Q Qᵀ A‖₂ ≤ (1 + √(k / (p − 1))) s_k+1
                  + (e √(k + p) / p) (∑_j>k s_j²)^(½)

    The tail term dominates when the spectrum decays slowly (Matérn-½ Gram matrices, most geophysical fields). q power iterations apply the bound to (A Aᵀ)^q A, whose singular values are s_j^(2q+1), at the cost of 2q more passes over A, so use n_power_iter >= 2 for slowly decaying spectra.

    Randomized methods target the top of the spectrum (the largest singular values). For the small end, use Lanczos or LOBPCG. A is touched only through mv (and the transpose's mv for power steps), vmapped over the ℓ columns.

    Algorithm
    1. Draw the Gaussian test matrix Ω, or take Ω = Sᵀ from sketch.
    2. Orthonormalise the sketch: Q = orth(A Ω).
    3. Repeat q times: Q̂ = orth(Aᵀ Q), then Q = orth(A Q̂).

    def range_finder(
    op: lx.AbstractLinearOperator,
    rank: int,
    *,
    oversample: int = 10,
    n_power_iter: int = 2,
    sketch: AbstractSketch | None = None,
    key: jax.Array | None = None,
) -> Float[Array, "m l"]:
    """Orthonormal basis Q for the dominant range of A.

        Q = orth((A Aᵀ)^q A Ω),   Ω ∈ ℝ^(N × ℓ),   ℓ = k + p

    For a Gaussian Ω and q = 0 (Halko, Martinsson & Tropp, 2011, Thm 10.6), with
    singular values s_j of A,

        𝔼 ‖A − Q Qᵀ A‖₂ ≤ (1 + √(k / (p − 1))) s_k+1
                          + (e √(k + p) / p) (∑_j>k s_j²)^(½)

    The tail term dominates when the spectrum decays slowly (Matérn-½ Gram
    matrices, most geophysical fields). q power iterations apply the bound to
    (A Aᵀ)^q A, whose singular values are s_j^(2q+1), at the cost of 2q more passes
    over A, so use ``n_power_iter >= 2`` for slowly decaying spectra.

    Randomized methods target the **top** of the spectrum (the largest singular
    values). For the small end, use Lanczos or LOBPCG. A is touched only through
    ``mv`` (and the transpose's ``mv`` for power steps), vmapped over the ℓ columns.

    Algorithm:
        1. Draw the Gaussian test matrix Ω, or take Ω = Sᵀ from ``sketch``.
        2. Orthonormalise the sketch: Q = orth(A Ω).
        3. Repeat q times: Q̂ = orth(Aᵀ Q), then Q = orth(A Q̂).

    Args:
        op: Operator A of size M × N; may be matrix-free.
        rank: Target rank k.
        oversample: Extra columns p; ℓ = k + p, capped at min(M, N). Ignored when
            ``sketch`` is given.
        n_power_iter: Number of power iterations q.
        sketch: Optional test matrix as a sketch S with ``in_size == N`` (e.g.
            `SparseSignSketch`, `SRHTSketch`), applied as its transpose, Ω = Sᵀ,
            with ℓ = ``sketch.out_size``. ``None`` draws a Gaussian Ω.
        key: PRNG key for the Gaussian test matrix. ``None`` means
            ``jax.random.PRNGKey(0)``. Ignored when ``sketch`` is given.

    Returns:
        The basis Q, M × ℓ, with orthonormal columns.

    Raises:
        ValueError: On a non-positive ``rank``, negative ``oversample`` or
            ``n_power_iter``, a sketch whose ``in_size`` is not N, or a sketch with
            fewer than ``rank`` rows.

    Examples:
        A rank-five matrix is recovered by its basis:

        >>> import einx
        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import lineax as lx
        >>> import gaussx
        >>> left = jr.normal(jr.key(0), (100, 5))
        >>> matrix = left @ jr.normal(jr.key(1), (5, 80))
        >>> op = lx.MatrixLinearOperator(matrix)
        >>> basis = gaussx.range_finder(op, 5, key=jr.key(2))
        >>> basis.shape
        (100, 15)
        >>> projection = einx.dot("row sketch, row col -> sketch col", basis, matrix)
        >>> bool(jnp.allclose(basis @ projection, matrix, atol=1e-4))
        True

        A sketch sets ℓ itself, so ``oversample`` no longer applies:

        >>> sketch = gaussx.GaussianSketch.sample(jr.key(3), 7, 80)
        >>> gaussx.range_finder(op, 5, sketch=sketch).shape
        (100, 7)

        A sketch of the wrong input size is rejected:

        >>> wrong = gaussx.GaussianSketch.sample(jr.key(3), 7, 60)
        >>> gaussx.range_finder(op, 5, sketch=wrong)
        Traceback (most recent call last):
        ...
        ValueError: sketch.in_size=60 must equal the operator's in_size=80.

    References:
        Halko, N., Martinsson, P.-G. & Tropp, J. A. (2011), Algorithm 4.4.
    """
    _check_args(rank, oversample, n_power_iter)
    out_size, in_size = op.out_size(), op.in_size()
    dtype = op.in_structure().dtype

    # --- test matrix ---
    if sketch is None:
        if key is None:
            key = jax.random.PRNGKey(0)
        # ℓ = min(k + p, M, N)
        sketch_size = min(rank + oversample, out_size, in_size)
        # Ω ~ 𝒩(0, I), N × ℓ
        test_matrix = jax.random.normal(key, (in_size, sketch_size), dtype=dtype)
    else:
        if sketch.in_size != in_size:
            raise ValueError(
                f"sketch.in_size={sketch.in_size} must equal the operator's "
                f"in_size={in_size}."
            )
        if sketch.out_size < rank:
            raise ValueError(
                f"sketch.out_size={sketch.out_size} must be at least rank={rank}."
            )
        # I_ℓ
        identity = jnp.eye(sketch.out_size, dtype=dtype)
        # Ω = Sᵀ
        test_matrix = sketch.apply_transpose(identity)

    # --- subspace iteration ---
    # A Ω
    image = _matmat(op, test_matrix)
    # Q = orth(A Ω)
    basis = _orth(image)
    if n_power_iter > 0:
        op_transpose = op.transpose()
        for _ in range(n_power_iter):
            # Aᵀ Q
            transpose_image = _matmat(op_transpose, basis)
            # Q̂ = orth(Aᵀ Q), so round-off does not lose the small directions
            transpose_basis = _orth(transpose_image)
            # A Q̂
            image = _matmat(op, transpose_basis)
            # Q = orth(A Q̂)
            basis = _orth(image)
    return basis

    def qb(
    op: lx.AbstractLinearOperator,
    rank: int,
    *,
    oversample: int = 10,
    n_power_iter: int = 2,
    key: jax.Array | None = None,
) -> tuple[Float[Array, "m l"], Float[Array, "l n"]]:
    """Randomized QB factorisation A ≈ Q B with B = Qᵀ A.

        A ≈ Q B,   B = Qᵀ A = (Aᵀ Q)ᵀ

    ‖A − Q B‖ is the range-finder error (see `range_finder` for its bound and the
    advice on ``n_power_iter >= 2`` for slowly decaying spectra). Randomized methods
    target the **top** of the spectrum.

    Algorithm:
        1. Find the basis Q with `range_finder`.
        2. Project with ℓ more transpose matvecs, B = (Aᵀ Q)ᵀ, so A is never formed.

    Args:
        op: Operator A of size M × N; may be matrix-free.
        rank: Target rank k.
        oversample: Extra columns p; ℓ = k + p, capped at min(M, N).
        n_power_iter: Number of power iterations q.
        key: PRNG key for the Gaussian test matrix. ``None`` means
            ``jax.random.PRNGKey(0)``.

    Returns:
        Tuple ``(Q, B)`` of the basis Q (M × ℓ) and the projection B (ℓ × N).

    Raises:
        ValueError: On a non-positive ``rank``, or a negative ``oversample`` or
            ``n_power_iter``.

    Examples:
        A rank-four matrix factors exactly at ℓ = 8:

        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import lineax as lx
        >>> import gaussx
        >>> left = jr.normal(jr.key(0), (60, 4))
        >>> matrix = left @ jr.normal(jr.key(1), (4, 40))
        >>> basis, projection = gaussx.qb(
        ...     lx.MatrixLinearOperator(matrix), 4, oversample=4
        ... )
        >>> basis.shape, projection.shape
        ((60, 8), (8, 40))
        >>> bool(jnp.allclose(basis @ projection, matrix, atol=1e-4))
        True

        ℓ is capped at min(M, N):

        >>> small = lx.MatrixLinearOperator(jnp.eye(3))
        >>> gaussx.qb(small, 2, oversample=10)[1].shape
        (3, 3)

        A negative ``oversample`` is rejected:

        >>> gaussx.qb(small, 2, oversample=-1)
        Traceback (most recent call last):
        ...
        ValueError: oversample must be non-negative, got -1.
    """
    # Q = orth((A Aᵀ)^q A Ω)
    basis = range_finder(
        op, rank, oversample=oversample, n_power_iter=n_power_iter, key=key
    )
    op_transpose = op.transpose()
    # Aᵀ Q
    transpose_image = _matmat(op_transpose, basis)
    # B = (Aᵀ Q)ᵀ
    projection = rearrange(transpose_image, "n l -> l n")
    return basis, projection

    Truncated SVD A ≈ U diag(s) Vᵀ by randomized QB.

    A ≈ Q B,   B = U_B diag(s) Vᵀ,   U = Q U_B

    The cost is (2q + 2) ℓ matvecs with A or Aᵀ, plus O((M + N) ℓ²) flops; A is never formed.

    Randomized methods target the top of the spectrum: the leading singular triplets are accurate, the trailing ones are not. Use n_power_iter >= 2 for slowly decaying spectra (Matérn-½ Gram matrices, most geophysical fields); see range_finder for the error bound.

    Algorithm
    1. Factorise A ≈ Q B with qb.
    2. Take the small SVD B = U_B diag(s) Vᵀ.
    3. Keep the top k triplets and lift the left vectors, U = Q U_B.

    		 10
    n_power_iter int

    		 2

    		 None

    """Truncated SVD A ≈ U diag(s) Vᵀ by randomized QB.

        A ≈ Q B,   B = U_B diag(s) Vᵀ,   U = Q U_B

    The cost is (2q + 2) ℓ matvecs with A or Aᵀ, plus O((M + N) ℓ²) flops; A is
    never formed.

    Randomized methods target the **top** of the spectrum: the leading singular
    triplets are accurate, the trailing ones are not. Use ``n_power_iter >= 2`` for
    slowly decaying spectra (Matérn-½ Gram matrices, most geophysical fields); see
    `range_finder` for the error bound.

    Algorithm:
        1. Factorise A ≈ Q B with `qb`.
        2. Take the small SVD B = U_B diag(s) Vᵀ.
        3. Keep the top k triplets and lift the left vectors, U = Q U_B.

    Args:
        op: Operator A of size M × N; may be matrix-free.
        rank: Number of singular triplets k to return (at most min(M, N)).
        oversample: Extra columns p in the range finder.
        n_power_iter: Number of power iterations q.
        key: PRNG key for the Gaussian test matrix. ``None`` means
            ``jax.random.PRNGKey(0)``.

    Returns:
        Tuple ``(U, s, Vt)`` holding U (M × k), s (length k, descending) and
        Vᵀ (k × N).

    Raises:
        ValueError: On a non-positive ``rank``, or a negative ``oversample`` or
            ``n_power_iter``.

    Examples:
        Five EOFs of an anomaly matrix available only as a matvec, here a small dense
        stand-in:

        >>> import einx
        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import lineax as lx
        >>> import gaussx
        >>> left = jr.normal(jr.key(0), (300, 8))
        >>> anomalies = left @ jr.normal(jr.key(1), (8, 120))
        >>> op = lx.MatrixLinearOperator(anomalies)
        >>> U, s, Vt = gaussx.randomized_svd(op, 5, key=jr.key(2))
        >>> U.shape, s.shape, Vt.shape
        ((300, 5), (5,), (5, 120))
        >>> pcs = einx.multiply("k, k time -> k time", s, Vt)
        >>> pcs.shape
        (5, 120)

        A ``rank`` above min(M, N) returns min(M, N) triplets:

        >>> small = lx.MatrixLinearOperator(jnp.eye(3))
        >>> gaussx.randomized_svd(small, 5)[1].shape
        (3,)

        A non-positive ``rank`` is rejected:

        >>> gaussx.randomized_svd(small, 0)
        Traceback (most recent call last):
        ...
        ValueError: rank must be a positive integer, got 0.

    References:
        Halko, N., Martinsson, P.-G. & Tropp, J. A. (2011), Algorithm 5.1.
    """
    # A ≈ Q B
    basis, projection = qb(
        op, rank, oversample=oversample, n_power_iter=n_power_iter, key=key
    )
    # B = U_B diag(s) Vᵀ
    small_left, singular_values, right_transpose = jnp.linalg.svd(
        projection, full_matrices=False
    )
    # min(k, ℓ)
    kept = min(rank, singular_values.shape[0])
    # U_B restricted to the top triplets
    top_small_left = small_left[:, :kept]
    # U = Q U_B
    left = einsum(basis, top_small_left, "m l, l k -> m k")
    return left, singular_values[:kept], right_transpose[:kept]

        keep = jnp.arange(ritz_values.shape[0] - kept, ritz_values.shape[0])

    Randomized Nyström¶

    For a PSD operator, randomized_nystrom returns the Nyström approximation \(\hat{\mathbf{A}} = (\mathbf{A}\boldsymbol{\Omega})(\boldsymbol{\Omega}^\top \mathbf{A} \boldsymbol{\Omega})^{+}(\mathbf{A}\boldsymbol{\Omega})^\top\) from one pass of \(\ell\) matvecs (Tropp, Yurtsever, Udell & Cevher, 2017, Algorithm 3). It satisfies \(0 \preceq \hat{\mathbf{A}} \preceq \mathbf{A}\) and, for the same \(\ell\), is more accurate than the Rayleigh–Ritz projection of randomized_eigh. The result is an orthonormal LowRankUpdate \(\mathbf{U} \mathrm{diag}(\hat{\boldsymbol{\gamma}}) \mathbf{U}^\top\), so the same factors on a \(\sigma^2 \mathbf{I}\) base solve and take log-determinants of \(\hat{\mathbf{A}} + \sigma^2 \mathbf{I}\) through the Woodbury rules. It is also the sketch behind NystromPreconditioner.

    root_size = jnp.sqrt(jnp.asarray(size, dtype))
    # √N ε
    relative_shift = root_size * jnp.finfo(dtype).eps
    # ‖Y‖₂
    image_norm = jnp.linalg.norm(image, 2)
    # ν = √N ε ‖Y‖₂, which only stabilises the small Cholesky and is removed below
    shift = relative_shift * image_norm
    # Y_ν = Y + ν Ω
    shifted_image = image + shift * test_matrix
    # Ωᵀ Y_ν
    core = einsum(test_matrix, shifted_image, "n a, n b -> a b")
    # sym(Ωᵀ Y_ν)
    core = symmetrize(core)
    # C Cᵀ = Ωᵀ Y_ν
    core_factor = jnp.linalg.cholesky(core)

    # --- singular values to eigenvalues ---
    # Y_νᵀ
    shifted_image_transpose = rearrange(shifted_image, "n l -> l n")
    # Bᵀ = C⁻¹ Y_νᵀ, so B Bᵀ = Y_ν (Ωᵀ Y_ν)⁻¹ Y_νᵀ
    nystrom_factor_transpose = jax.scipy.linalg.solve_triangular(
        core_factor, shifted_image_transpose, lower=True
    )
    # B = Y_ν C⁻ᵀ
    nystrom_factor = rearrange(nystrom_factor_transpose, "l n -> n l")
    # B = U diag(s) (…)ᵀ
    left, singular_values, _ = jnp.linalg.svd(nystrom_factor, full_matrices=False)
    # min(k, ℓ)
    kept = min(rank, sketch_size)
    # U restricted to the top k
    eigenvectors = left[:, :kept]
    # s_1:k
    top_singular_values = singular_values[:kept]
    # s²
    squared = top_singular_values**2
    # γ̂ = max(s² − ν, 0)
    eigenvalues = jnp.maximum(squared - shift, 0.0)
    # 0, the diagonal base
    zeros = jnp.zeros(size, dtype=dtype)
    # V is U (the same object), so the update is symmetric and PSD-tagged.
    return svd_low_rank_plus_diag(
        zeros, eigenvectors, eigenvalues, eigenvectors, psd=True
    )

    def cur(
    op: lx.AbstractLinearOperator,
    rank: int,
    *,
    oversample: int = 10,
    n_power_iter: int = 2,
    key: jax.Array | None = None,
) -> CUR:
    """Randomized CUR decomposition (Voronin & Martinsson, 2017, §4).

        A ≈ C U R,   C = A_:,J,   R = A_I,:,   U = X R⁺

    C U R = C X R⁺ R is the column ID with X replaced by its projection onto the row
    space of R. The error is that of the column ID, amplified by a factor that depends
    on the row selection's conditioning, ‖R⁺‖ (Voronin & Martinsson, 2017, §4); it is
    exact when rank(A) ≤ k.

    Algorithm:
        1. Take the column ID A ≈ A_:,J X with `column_id`.
        2. Read C = A_:,J (k matvecs).
        3. Take the column-pivoted QR of Cᵀ, whose permutation gives I = P_1:k.
        4. Read R = A_I,: (k transpose matvecs) and set U = X R⁺.

    Args:
        op: Operator A of size M × N; may be matrix-free.
        rank: Number of columns and rows k, at most min(M, N).
        oversample: Extra sketch rows p for the column ID.
        n_power_iter: Power iterations q for the column ID.
        key: PRNG key for the sketch. ``None`` means ``jax.random.PRNGKey(0)``.

    Returns:
        A `CUR` ``(columns, rows, C, U, R)``.

    Raises:
        ValueError: If ``rank`` is outside [1, min(M, N)], or on the `gaussx.qb`
            errors.

    Examples:
        A rank-five matrix is exact on five of its columns and rows:

        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import lineax as lx
        >>> import gaussx
        >>> left = jr.normal(jr.key(0), (60, 5))
        >>> matrix = left @ jr.normal(jr.key(1), (5, 40))
        >>> decomposition = gaussx.cur(lx.MatrixLinearOperator(matrix), 5)
        >>> reconstruction = decomposition.C @ decomposition.U @ decomposition.R
        >>> bool(jnp.allclose(reconstruction, matrix, atol=1e-3))
        True
        >>> bool(jnp.array_equal(decomposition.R, matrix[decomposition.rows]))
        True

        A non-positive ``rank`` is rejected:

        >>> gaussx.cur(lx.MatrixLinearOperator(matrix), 0)
        Traceback (most recent call last):
        ...
        ValueError: rank must be in [1, min(m, n)] = [1, 40], got 0.

    References:
        Voronin, S. & Martinsson, P.-G. (2017). Efficient algorithms for CUR and
        interpolative matrix decompositions. *Advances in Computational Mathematics*,
        43(3), 495-516.
    """
    # A ≈ A_:,J X
    columns, interpolation = column_id(
        op, rank, oversample=oversample, n_power_iter=n_power_iter, key=key
    )
    # Cᵀ, the selected columns as rows, k × M
    columns_as_rows = _select(op, columns)
    # Cᵀ P = Q_C R_C
    _, _, permutation = jax.scipy.linalg.qr(
        columns_as_rows, mode="economic", pivoting=True
    )
    # I = P_1:k
    rows = permutation[:rank]
    op_transpose = op.transpose()
    # R = A_I,:
    selected_rows = _select(op_transpose, rows)
    # R⁺
    pseudo_inverse = jnp.linalg.pinv(selected_rows)
    # U = X R⁺
    linking = einsum(interpolation, pseudo_inverse, "k n, n row -> k row")
    # C
    selected_columns = rearrange(columns_as_rows, "k m -> m k")
    return CUR(columns, rows, selected_columns, linking, selected_rows)
